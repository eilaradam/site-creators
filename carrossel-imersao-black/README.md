# Carrossel collab · Imersão de Black

10 slides 1080x1350 (4:5) em Remotion, estilo chat (balão claro = Lara, balão escuro = Camila).

1. Fotos: coloque em `public/` e preencha os nomes em `src/config.ts`.
2. Textos pendentes (`[...]`) também ficam em `src/config.ts`; enquanto tiverem colchetes, aparecem tracejados.
3. `npm install`, depois `npm run studio` para ajustar e `npm run render` para gerar os PNGs em `out/`.
